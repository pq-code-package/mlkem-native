# HOL Light proofs for the RISC-V 64 backend (in preparation)

This directory will hold the HOL Light proofs for the RISC-V 64 assembly in
[dev/riscv64/src](../../../dev/riscv64/src). No proofs exist yet.

## Status

- [mlkem/](mlkem) contains the assembly that the proofs will verify. It is
  generated by `scripts/autogen` from `dev/riscv64/src` using `scripts/simpasm`,
  in the same way as for [aarch64](../aarch64) and [x86_64](../x86_64).
- The assembly is built with `.option norvc` and `.option norelax`, so the byte
  code contains no compressed instructions and the linker cannot rewrite it.
  The object code verified by HOL Light is therefore exactly the code that is
  linked into the library.

## Prerequisite: an RV64 + RVV model in s2n-bignum

s2n-bignum[^s2n-bignum] currently provides a partial RV32IM model only
(`riscv/` in the s2n-bignum repository). The proofs here need:

1. **RV64IM:** 64-bit registers and addresses, and the RV64-only instructions
   (`addiw`, `slliw`, and similar). The base and M instructions used by the
   kernels are few.
2. **The vector extension (RVV 1.0):** the vector register file, the `vl` and
   `vtype` state, `vsetvli`, and the vector instructions used by the kernels.
   The model must reflect two kinds of freedom the specification gives to
   implementations:
   - For `VLMAX < AVL < 2*VLMAX`, `vsetvli` may return any `vl` in
     `[ceil(AVL/2), VLMAX]`.
   - With the tail-agnostic and mask-agnostic policies (`ta`, `ma`), inactive
     elements may be left unchanged or overwritten with all ones.

   Both should be modelled nondeterministically, so that a proof covers every
   conforming implementation.

`VLEN` should be a parameter of the model. Kernels written for a fixed `VLEN`
(NTT and inverse NTT, `VLEN=128` and `VLEN=256`) can then be proved for that
value, and the vector-length agnostic kernels for all `VLEN`.

## Planned specifications

The specifications follow the AArch64 ones in [aarch64/proofs](../aarch64/proofs).
All functions except rejection sampling also need constant-time proofs.

| Function | VLEN | Specification |
|----------|------|---------------|
| `ntt_vlen128_riscv64_asm`, `ntt_vlen256_riscv64_asm` | 128, 256 | For inputs bounded by q in absolute value, the output is congruent mod q to the NTT of the input, in bitreversed order, and bounded by 8q. |
| `intt_vlen128_riscv64_asm`, `intt_vlen256_riscv64_asm` | 128, 256 | The output is congruent mod q to the inverse NTT of the input, times 2^16, and bounded by 8q. |
| `poly_reduce_riscv64_asm` | any | Each output coefficient is the unsigned canonical representative mod q of the input coefficient. |
| `poly_tomont_riscv64_asm` | any | Each output coefficient is congruent mod q to the input coefficient times 2^16, and bounded by q. |
| `polyvec_basemul_acc_montgomery_cached_k{2,3,4}_riscv64_asm` | any | For `a` in [0, 4096), the output is congruent mod q to the scalar product of `a` and `b` in NTT domain (using the multiplication cache of `b`), times 2^-16. |
| `poly_mulcache_compute_riscv64_asm` | any | Each cache entry is congruent mod q to the second coefficient of the corresponding pair times its twiddle, and bounded by q. |
| `keccak_f1600_x1_zbb_riscv64_asm` | n/a (scalar, Zbb) | The state is replaced by the Keccak-f[1600] permutation of the input state. |
| `rej_uniform_riscv64_asm` | any | The output is the first `len` 12-bit values from `buf` that are below q; the function returns their number. No constant-time proof is needed (public data). |
